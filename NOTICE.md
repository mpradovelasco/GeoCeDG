# GeoCeDG notices

GeoCeDG is an independent source-based fork for Computer-Extended Descriptive
Geometry. It is not an official GeoGebra product and is not endorsed by the
GeoGebra project.

Baseline source: GeoGebra 5.4.928.0,
`9b93256b7df401ff056c37b502d82df4d72b1522`.

The G4 package uses the GeoCeDG name and launcher, but the current runtime still
contains inherited code, translations, UI resources, fonts, and third-party
libraries. Their complete redistribution audit is not closed. No upstream
installer, scientific PDF, `Templatev7.ggb`, or legacy/research model is an
intentional package input.
