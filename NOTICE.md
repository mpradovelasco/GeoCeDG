GeoCeDG is an independent source-based fork for Computer-Extended Descriptive
Geometry. It is not an official GeoGebra product, is not endorsed by GeoGebra
GmbH, and uses its own product name and packaging.

Upstream baseline: GeoGebra 5.4.928.0,
`9b93256b7df401ff056c37b502d82df4d72b1522`.

The source tree contains inherited GeoGebra code under EUPL-1.2. The Windows
runtime also retains GeoGebra Language Files and Materials under the applicable
GeoGebra non-commercial terms. A public PROFILE NC package must preserve the
GeoGebra attribution required by those terms, including “Made with GeoGebra”
where applicable, without implying endorsement.

GeoCeDG-authored software and scripts use EUPL-1.2 by author disposition.
GeoCeDG-authored documentation and ordinary artwork use CC BY 4.0 subject to
recorded exceptions. Copyright licensing for the official artwork does not
grant a right to present a modified fork as the official GeoCeDG product.

The package legal directory contains this notice, the root license scope, the
third-party component register, exact license texts, asset provenance, resolved
dependency identity, and source-access information. The jlink runtime retains
its module-specific `runtime/legal/**` tree.

intentional package input.

professional legal review remain required.

## Distribution condition

This notice is profile-neutral.The distribution condition of a
particular build is profile-specific and is stated by the distribution notice
packaged with it: INTERNAL_EVALUATION_ONLY.txt for PROFILE INTERNAL, which is
an internal evaluation artifact and must not be redistributed, and
NC_DISTRIBUTION_NOTICE.txt for PROFILE NC, which may be redistributed only
under its approved non-commercial terms. Commercial distribution is not
authorized.
