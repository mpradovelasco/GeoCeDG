# GeoCeDG model repository

Models are durable validation or research inputs, not generated evidence.
Every future model or tool package requires a versioned manifest with
provenance, validity, degeneration, metric, compatibility, and license data.

G1 contains only the manifest contract and an empty catalog. It imports no
`.ggb`, `.ggt`, GeoGebraScript, screenshot, or legacy CeDG asset. Future
canonical, regression, research, legacy, and stress-model content must be
introduced by its authorized roadmap gate.
