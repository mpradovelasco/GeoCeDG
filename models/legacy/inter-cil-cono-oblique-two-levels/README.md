# InterCilConoObliqueTwoLevels legacy research model

This package preserves the author-supplied
`InterCilConoObliqueTwoLevels.ggb` companion model as independent G6A
evidence. The author accepted it as the functional two-level legacy control,
measured at approximately 125–127 ms. It is not assumed to be equivalent to the other oblique
cone-cylinder file merely because both describe the same scientific workflow.

The stored construction contains thirteen legacy loci and a point `L_2` on
`loc11`. That makes the sampled `GeoLocus` path behavior directly observable.
The file has no `Flatten` button and differs structurally from
`InterCilConoOblique.ggb`; G6A therefore measures it as a pre-materialized
state rather than treating it as the expected output of the button.

The original is immutable and pinned by the manifest SHA-256. Redistribution
remains blocked pending rights/asset review. Use the CeDG Laboratory only for
explicit research inspection.
