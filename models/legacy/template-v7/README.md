# Templatev7 legacy CeDG package

`original/Templatev7.ggb` is the byte-identical historical template supplied by
the author. Its SHA-256 is
`f62e5b7a92bcd95f10b8afda348763a57ccbd0c10dbc0c2bccc7049831ed4113`.
Do not edit or resave it.

The source container was written by GeoGebra Classic Desktop 5.2.879.0 and
contains 24 macros, seven custom toolbar groups, document scripting, and global
JavaScript. The ordered toolbar is authoritative evidence of the legacy CeDG
workflow, but it is not a constraint on the future GeoCeDG toolbar.

`curation.yml` records scientific and architectural interpretation.
`derived/tool-inventory.yml` is generated by `tools/legacy/ingest.ps1` and must
not be edited manually.

Validate or open it explicitly:

```powershell
.\tools\legacy\ingest.ps1 -ResourceId cedg.legacy.template-v7 `
  -Source models/legacy/template-v7/original/Templatev7.ggb `
  -TargetDirectory models/legacy/template-v7 -Check

.\tools\legacy\open-laboratory.ps1 -ResourceId cedg.legacy.template-v7
```

Use `-Classic` on the Laboratory command for the upstream diagnostic route.
The resource is never loaded by default and remains blocked from packaging
until its embedded code and assets pass human rights review.
