# InterCilConoOblique legacy research model

This package preserves the author-supplied `InterCilConoOblique.ggb` model as
G6A scientific and performance evidence. The author accepted it as the
pathological third-level legacy reference. It is not loaded by default and is
not a Locus V2 implementation or regression authority.

The stored construction contains ten legacy loci. `loc9` is measured through
`Perimeter`, that result contributes to `loc10`, and `loc10` is measured again.
The document-owned `Flatten` button requests three further legacy loci. G6A
characterizes these stages separately so button execution is not confused with
normal file loading. The accepted G6A run measured approximately 31.9 ms before
`Flatten`, 6.03/5.95/5.67 s for the three creations, undefined outputs after
the 500 ms legacy step guard, and approximately 21.0 s after the attempt.

The original is immutable and pinned by the manifest SHA-256. Redistribution
remains blocked pending rights/asset review. Use the CeDG Laboratory only for
explicit research inspection.
