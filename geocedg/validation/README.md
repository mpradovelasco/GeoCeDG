# GeoCeDG validation sources

This directory owns invariant definitions, tolerance policies, analytic
references, and approved regression baselines. Generated test output belongs
under ignored `artifacts/`, not here.

The `locus-v2/` records are the author-approved G6A characterization evidence
and future G6B validation inputs. The normative geometric authority is the G6
semantic specification; these versioned records do not implement a product V2
object and G6B remains not started.
