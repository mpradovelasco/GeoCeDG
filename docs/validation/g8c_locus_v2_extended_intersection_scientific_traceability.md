## Scientific pilots

1. **Cone–cylinder LSIM multileaf pilot.** Preserve four constructive leaves and
   transitions between bite and penetration. Historical samples are qualitative
   regression input, never numeric truth.
2. **Focal illumination/separatrix pilot.** Exercise two intersections,
   tangency and empty state as the controlling geometry changes.
3. **Intersection-to-flattening chain.** Use an identified intersection output
   as input to a subsequent construction and verify normal invalidation.
4. **Locus–locus composition.** Prefer a hash-pinned reproducible model if the
   catalog supplies one; otherwise use the independently declared parametric
   fixtures and record the absence rather than fabricating provenance.

## Source boundary

The corpus establishes CeDG method, constructive dependency, multileaf topology,
dynamic qualitative change and the limits of legacy sampled Locus. It does not
select Newton, interval boxes, tolerances, token algorithms, residual
normalization, or completeness claims. Those derive from normative G6/G8
contracts, Accepted ADRs, actual source architecture, and reproducible G8C
evidence.
