## 1. Author decision (essentials)

- **E5 popup.** The GeoCeDG line-style popup that holds the numeric thickness editor may be
  a light-weight popup without the FlatLaf drop shadow. The change is scoped to that one
  GeoCeDG control. Global Swing popup settings, every other GeoCeDG popup and Classic keep
  their behaviour. The E5 probe was feasibility evidence, not an accepted implementation.
- **Horizontal layout.** The line-type table stays above. Below it, the existing slider
  and, immediately to its right on the same row, the numeric editor, vertically aligned
  with the slider. The editor is compact, sized from font metrics and insets (no fixed
  pixel widths). Resizing, display scaling, keyboard navigation and accessibility are
  preserved. There is no independent thickness value or duplicated state, and the slider
  listeners and actions are unchanged. A GeoCeDG-owned horizontal container is preferred.
- **Not authorized.**
  - architecture A2;
  - any change to `PopupMenuButtonD`, `EuclidianStyleBarD`, `GuiManager3D` or another
    inherited frontend class;
  - shared kernel or geometric semantics;
  - additional features.
- **Gate first.** The complete real-window gate (§4) runs before any candidate. It uses
  the E5 implementation and the layout, the real application with isolated settings,
  native input (`java.awt.Robot`) and the product runtime Temurin 25.0.4 with its
  launch configuration.
  - Pass: `F4-A E5 FOCUS FEASIBILITY = PASS`.
  - Product failure: `STOP — F4-A E5 FEASIBILITY FAILED`.
  - Native input unavailable: `GATE NOT EXECUTED — ENVIRONMENT BLOCKED`.
- **Heavy-weight case.** If the runtime selects a heavy-weight popup, the field must not
  look editable while unable to take focus. Any fallback or restricted availability is
  characterized and presented for the author's disposition before acceptance.
- **Input safety.** No editing or destructive key unless the field is confirmed as the
  keyboard focus owner; abort when focus or activation is uncertain. No change to
  integrity levels, UAC or other security settings.
- **Verification.** Then the A1 implementation per the canonical prompt, and `PHASE
  PRE-G9B-R6-PLUS-F4-A`, `INFRA_UNIT` and `STATIC` on the clean committed candidate.
  The phase inventory and pins are regenerated by the official mechanisms. Pre-commit runs
  are not acceptance.

## 3. Impact analysis and class

- **Affected control.** The change is confined to the GeoCeDG style bar
  (`GeoCeDGEuclidianStyleBar`), installed for Graphics 1 (`GeoCeDGEuclidianView`) and
  Graphics 2 (`GuiManagerGeoCeDG`). Only the popup of its own line-style button changes.
  That popup is a new object on every `createButtons()`, and the change is made on it
  through the component ancestry of the slider and the field.
- **Popup rendering.** `JPopupMenu.setLightWeightPopupEnabled` and the FlatLaf client
  property act on that one popup. The application-wide default set by the inherited
  `GuiManager3D` is untouched.
- **Unaffected.** The 3D view's own style bar, the Properties panel, the plane and Classic
  views do not use `GeoCeDGEuclidianStyleBar`.
- **Unchanged semantics.** Thickness property, range, validation, undo, serialization and
  kernel are as in the original F4-A scope.
- **Class.** `BOUNDED_PHASE` is maintained: the registered PHASE selection (Graphics 1
  and 2 lifecycle, Properties field, guides) covers the perimeter. The popup layering over
  the 3D view and near window bounds is a native-rendering question that no executable
  profile can see. The real-window gate (§4) covers it as focused evidence.

## 4. Plan

1. Reuse the WIP selectively. Replace the failed focusability fallback with the E5
   presentation and the horizontal row. When the popup is not shown inside the window
   (heavy-weight), disable the field.
2. Real-window gate on Temurin 25.0.4 (runGeoCeDG JVM arguments, isolated settings,
   `java.awt.Robot`). It covers the fifteen items of the instruction and the 3D
   compatibility gate: 3D view docked beside Graphics, the popup overlapping the 3D view,
   resized windows, and positions near the window bounds. Display scaling is checked with
   `sun.java2d.uiScale` and with the GeoCeDG font size. Keys are guarded by a confirmed
   focus owner.
3. On PASS: focused tests, EN/ES guide, provenance manifest, phase selection, inventory
   and pins through the official mechanisms. Then a clean candidate and the official
   PHASE, INFRA_UNIT and STATIC runs.
4. On a product failure: stop and record. On an environment block: record
   `GATE NOT EXECUTED — ENVIRONMENT BLOCKED`.
