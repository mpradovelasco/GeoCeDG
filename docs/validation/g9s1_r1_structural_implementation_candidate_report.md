## Mathematical and kernel correction

[ADR 0022](../adr/0022-structural-spline-continuity.md) and the
[structural architecture](../architecture/g9s1_r1_structural_spline_continuity.md)
define the exact authority. Open splines use one truncated-power representation
`sum(a_p t^p) + sum(b_j (t-k_j)_+^d)`. Its jets through `d-1` agree exactly at
simple knots; the space has `N+d-1` degrees of freedom. It retains every actual
native interpolation and fixed-span boundary equation, including the unusual
higher-degree boundary rows. No natural/not-a-knot substitution is made.

Closed splines separately eliminate all periodic jet constraints exactly in a
triangular system, with common denominator `d!` and `N-1` free coordinates.
Knots denote exact binary64 values. Free coefficients denote exact binary64 or,
under the authorized bounded fallback, stable retained finite decimal values;
exact decimal numerators preserve interior and seam identities. Approximate
endpoint equality is not exact periodic closure; inconsistent endpoints fail
closed. Signed zero does not create a false difference.

`SplinePolynomialModel2D` owns the new `SplineStructuralModel2D` authority.
`PiecewisePolynomialLocus2D` exposes exact numerator/denominator information;
model, evaluator and capability signatures are versioned v2. Rounded expanded
spans remain approximate evaluation data. `SplineIntervalModel2D` derives and
checks outward enclosures from exact structural numerators, never from assumed
equality of rounded adjacent spans. R5 maps remain enclosed in captured original
composition order. Classic Spline and productive frontend code are unchanged.

Direct reduced solving was selected over post-solve projection, which would
retain the large system and require an additional displacement/revalidation
contract. General B-spline/NURBS architecture is outside scope. The space
argument is supported by de Boor's primary spline exposition; periodic
elimination is a source-specific derivation, not an attributed theorem. Sources
and exact distinction between theorem, derivation and engineering criterion
are in the [numerical note](../research/g9s1_r1_structural_spline_numerics.md).
