## Creation contract and actual provider perimeter

For a complete address `a=(source,provider,branch,component,u,lift,seam)`, the point
is the normal forward construction `P=F(a)`. Click and Q supply the same transient
world request. Q is not a new parent. Selecting an address fixes its semantic
preimage, not a nearest-position identity or an inverse formula.

`INDIVIDUAL_FORWARD_ADDRESS_CREATION` has its own explicit permission, private
single-use choices and sealed publication. It independently establishes current
durable source/definition/provider/revision; faithful reconstructible class-v3
capture; coherent document authority; COMPLETE existence inventory; certified
positive-dimensional component and structural selector correspondence; complete
canonical address; and finite valid normal forward binding of that address.
Active constructive authority without an approved transfer is rejected. This
first table excludes arbitrary evaluators, incomplete inventories, point/collapsed
components, collapse and unsupported captures. H1's existing local perimeter is
preserved, including its own component/evidence guarantees.

C1, a nonzero jet, local/global injectivity, distance minima and inverse search
completeness are not universal prerequisites for creating an explicit forward point.
The initial new route reports only `FLOATING_POINT_UNCERTIFIED` target proximity:
the finite residual is a discovery threshold under the declared world radius,
not a certified ideal-distance bound, STRICT, minimum or uniqueness. One offer
still requires confirmation. Singularities unresolved by existence, correspondence,
discovery or forward evaluation remain barriers.

Each new operation bounds discovery, validation, confirmation and point publication.
The facade debits completed R1 and H1 semantic work before opening another permission;
actual nested R1 misses are retained separately without changing its historical
result telemetry. Cache clearing never resets charged work. A publication failure
is terminal. Prepared normal bindings avoid an uncounted repeated point evaluation.

The ordinary Point tool retains an earlier historical R6 query using its captured
hit radius. Its unresolved outcome may open a separate contextual query under the
panel's explicit world policy. The facade's cumulative counters cover that shared
operation, not the earlier UI query or the whole gesture. Both operations remain
bounded; their overhead is separate. Click/Q parity means the same copied world
request and the same explicit policy, not equality between different hit/panel radii.
This preserves the previously admitted direct R6 workflow; no such repeated global
discovery is added to the new drag provider.

## Drag contract and limits

Only a live point with the existing interaction output role and dedicated address
inputs is editable. Explicitly defined points with other roles are not converted.
An opaque kernel context belongs to one real gesture, point, source, revision and
expected accepted address. The old address constrains continuation; it does not
authorize it. Desktop supplies requests and owns the gesture; it does not solve
geometry or choose a semantic chart.

Two new sufficient providers supplement historical R6/Spline movement:

* A structurally proved invertible affine image of a circular driver. The narrow
  typed operation table is evaluated with outward interval arithmetic, without
  fitting samples. The request must remain inside the open hemisphere chart
  anchored by the current address. Driver-circle structural periodic correspondence
  follows the approved class-v3 totality contract, section 10.8; it is distinct
  from the older interval model's period=0. The centre, antipode, ill-conditioned
  unresolved inverse and unsupported program remain barriers.
* A reconstructible construction with a coordinate derivative of strict sign
  throughout the complete local chart containing the old and proposed arguments.
  The coordinate is retained for the entire gesture; it does not switch between
  events. The monotone inverse encloses parameter error within the declared
  tolerance. An ambiguous midpoint is not admitted merely by a small world residual.
  Only the current certified component is required for this independent local
  proof; global inverse or existence completeness is not inferred. Unproved seams,
  gaps, endpoints outside the chart and unresolved predicates stop continuation.

These proofs establish a local semantic sheet and continuous selection there,
without global injectivity. Numerical representatives retain the declared
parameter error. They do not promise traversing all singularities or finding all
nearby preimages. Same-image directions on another branch/component are never
selected by Cartesian proximity. A rejected new-chart request leaves the last valid state
and stops that context; a new press is required to start another attempt. This
also prevents re-entry after a rejected interval from acquiring a distant address.
Historical R6/Spline retains its own approved failed-event recovery behavior.

Successful edits preserve P and its durable ID, update only the dedicated semantic
state through the normal DAG, and use one normal construction transaction. Prepared
binding is one-use and checked against the old address and revision. Rejections
have no construction or Undo effect; one changed gesture has one Undo boundary.
No new point, generic Path conversion, codec, inverse parent or reconstruction
architecture is introduced. Copy/remap and `.cedg` reuse the existing forward form.

## Interface, fixed/free and P2

`Allow dragging` / `Permitir arrastre` defaults true. False applies the native
persistent lock; it does not freeze world coordinates or sever the source DAG.
The normal lock can later change that choice, while kernel continuation permission
remains separately required.

The ordinary Point/Point on object panel also offers reference Q for native 2D
segments, lines, rays and conics. It delegates to the existing native point-on-path
constructor, declares native numerical selection and keeps Q transient. Creation
and lock occur in the normal atomic transaction. 3D objects, arbitrary Paths,
regions, lists, legacy loci and auxiliary axes outside construction order remain
outside this additional Q table; their ordinary tools keep inherited behavior.

P2 is corrected for the ordinary semantic source selector: view, world coordinates
and world radius are captured before the modal source choice. A zoom/pan during
selection cannot reinterpret the old screen click. A changed view instance rejects
the request. Hit-testing and DPI select a frontend request, never its semantic address.
