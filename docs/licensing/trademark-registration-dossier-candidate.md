# GeoCeDG Spanish trademark registration dossier candidate

Prepared 2026-09-15 for author/professional review. No application has been
filed. This is procedural research, not a clearance opinion.

## Recommended filing sequence

1. Search the OEPM locator/database and EUIPO TMview/eSearch for identical and
   similar word, phonetic and figurative marks in relevant classes.
2. Have a Spanish trademark professional review distinctiveness, conflicts,
   owner data and the final goods/services list.
3. File `GeoCeDG` first as an OEPM national **word mark** in standard
   characters. It protects the stable verbal identity and survives logo
   evolution.
4. Initially select class 9 for the actual downloadable software activity.
   Add classes 41 and/or 42 only if the owner genuinely offers those services
   and accepts their additional scope/cost/exposure.
5. File a separate figurative/logo mark only after the visual identity is
   sufficiently stable and its filing-quality representation is approved.
6. Consider an EUIPO European Union trade mark when real multi-country EU use
   or launch plans justify unitary EU-wide coverage. National-first is the
   proportionate current route for an activity centered in Spain; an EUTM is
   unitary and objections/conflicts can affect the whole EU filing.

## Candidate Nice classes and wording

The Nice Classification 13th edition (2026) is the current edition. Final
wording must be selected in the OEPM goods/services classifier at filing.

| Class | Current/foreseeable role | Candidate wording for review |
|---:|---|---|
| 9 | current downloadable desktop product | “Downloadable computer software for dynamic geometry, descriptive geometry, geometric construction, visualization, measurement, validation and educational use; downloadable computer software for creating, editing and exchanging geometric construction files.” |
| 41 | only if education/training is actually provided as a service | “Education and training services relating to descriptive geometry, dynamic geometry and computer-assisted geometric construction; provision of non-downloadable educational materials in those fields.” |
| 42 | only if software/SaaS/design services are actually offered | “Design, development, maintenance and updating of computer software for geometry and education; software as a service featuring software for dynamic and descriptive geometry.” |

Class 9 protects downloadable goods; class 41 covers education/training
services; class 42 covers software development/design and SaaS. Repository
documentation alone does not automatically justify service classes.

## Filing evidence/assets checklist

- clearance-search record and professional review;
- exact word representation and owner data;
- approved Nice list selected from official terminology;
- for a figurative filing, a clean approved representation matching the
  versioned manifest asset and suitable OEPM format;
- proof of authority/assignment if an entity rather than the creating author
  files the mark;
- fee and electronic-signature/payment readiness at the time of filing;
- internal record connecting any filed figurative representation to semantic
  asset ID and version, not merely a filename.
