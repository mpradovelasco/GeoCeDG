# GeoCeDG trademark registration - filing evidence

This directory contains public repository evidence related to the Spanish trademark filing for **GeoCeDG**.

Current legal-status description for repository use:

`APPLICATION FILED — REGISTRATION PENDING`

This status applies only to the denominative mark identified below.

## Filing evidence

- **Authority:** Oficina Española de Patentes y Marcas (OEPM)
- **Filing type:** Trademark for goods or services
- **Sign:** `GeoCeDG`
- **Sign type:** Word mark (denominative), standard characters
- **Application number:** `M4403138`
- **Electronic filing date and time:** `2026-09-16 12:09:08`
- **Nice class:** `09`
- **Goods/services text in the filing:** archivos multimedia grabados o descargables, software, soportes de registro y almacenamiento digitales o analogos virgenes

The filing receipt evidences the **electronic submission of the application**. It does not by itself evidence registration or grant of the trademark. Any later prosecution or registration status must be documented separately from the corresponding OEPM evidence.

The public copy is derived from the official OEPM filing receipt. The following information has been deliberately removed from the repository copy:

- applicant name and identifying document number;
- nationality/residence/establishment values associated with the applicant;
- postal address and location details;
- email address and telephone number;
- telematic registry transaction identifier;
- payment barcode/reference.

The redaction removes the underlying PDF content rather than merely covering it visually. Pages not containing material selected for redaction remain unchanged in visual content.

## Private original

The unredacted OEPM receipt is **not intended to be versioned in the public GeoCeDG repository**. It should be retained in the project's private legal/administrative archive as the authoritative original evidence.

Do not replace the private original with this redacted copy: the redacted PDF is only the public repository evidence.
