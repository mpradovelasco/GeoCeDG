## Classification, boundaries and authorities

This is implementation with causal debugging and real Desktop validation.
Scientific geometry and durable state remain in the shared kernel. Desktop
owns ordinary tool flow, contextual selection, event dispatch and presentation.
Native Path placement/editing must use GeoGebra's existing authority; V2 uses its
explicit forward-address creation and certified continuation contracts. A common
UI is not a common geometric solver. Render, screen hit testing and an existing
point's selection do not establish editing permission or semantic direction.

Source authority is code/tests, approved specifications and ADRs, then exact
upstream baseline. The R3/R4 independent audits and R4 receipts are preserved
historical evidence. In particular, R4's audit explicitly did not execute
physical smoke; its `ACCEPTABLE WITH CONDITIONS` does not contradict the author's
new GUI counterexamples or constitute R5 acceptance. Existing R4 headless/AWT
PASS results cannot be relabelled as real window input.

The editable set is the smallest causal Desktop/kernel adapters and tests
identified by the three implementation investigations, this validation design,
the current bilingual guide entries and capability traceability, and the typed
PHASE/JUnit registry and its focused assertions. Do not edit historical fixtures,
audit probes, reports, SHA manifests, main, book or accepted R6/H1 contracts.

## Separate causal and acceptance records

R5-A traces mouse press, hit selection, move-mode choice, drag receipt, world
request, typed continuation, semantic address, DAG/repaint, release and Undo.
Locate the first broken boundary in R4 before implementation. Reopened and newly
created interactive points need separate positives; blocked interaction must
preserve dynamic dependency.

R5-B records source/revision/domain/component, actual captured world target and
radius, provider/creation permission, offers, forward existence, structural
selection and reason for failure. A restrictive projection route must not hide
another expressly authorized forward-address route. Neither a numerical search
nor metric proximity is itself a construction permission. F8 remains disabled.

R5-C records discovery and availability of the ordinary native Q workflow before
correction. New reference placement is transient and uses the native Path
contract; Q must not become a permanent parent. Preserve ordinary click without
a mandatory new dialogue. Test native circle, segment and parabola as minimum
families and expose other families only through real supported Path capability.

embedded-controller tests, helper calls and kernel tests are distinct evidence.

impediment; never assert readiness while a required workflow fails/unverified.
No source change after a GUI result inherits that result automatically: repeat
affected gates against the replacement executable and record the new identity.
