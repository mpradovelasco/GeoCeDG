## F1/F3 — Two distinct fidelity permissions

FILE_EXACT_NATIVE_STATE and ROLLBACK_EXACT_TYPED_STATE are different claims.
Local equality between a live native point and native F(t) does not establish
that the defining source will reconstruct with identical state after file load.

The version-1 conic writer must require positive transitive fidelity of the
pertinent defining closure, including inline inputs/lists and native editable
ancestors. Unproved or lossy ancestors suppress the new field and retain the
historical readable payload; they do not receive a false exact-file guarantee.
The valid new-format reader remains strict. No saved document may become
unreadable in its own runtime because an ineligible conicPointState was emitted.
Dynamic ancestor changes require fresh classification; no invented global
native revision or stale cached Boolean establishes this permission.

Baseline F1 has been reproduced BEFORE code: the unmodified auditor's
IndependentNativeAncestorAuditTest fails on the exact 68b14 code with
Invalid native conic point state; removing only the new field makes the same
native chain readable. The new R3 run and its original failure are preserved.

Extend the existing atomic construction transaction with a focal typed native
state complement in memory. Priority table: native free 2D points on line, ray,
segment, full conic and circular arc, preserving raw coordinates/caches,
parameter/type, fallback, animation and native source/domain/orientation.
XML remains the normal host/DAG reconstruction; typed state restores only
the demonstrated native editable state that XML alone cannot preserve.

Use existing PersistentGeoId bindings where available. An unrelated ordinary
native point without a durable ID must not be rejected merely for that absence.
If necessary, use snapshot-scoped opaque RollbackSnapshotKey bindings carried
only in the private snapshot and recognized only by its active rollback session.
Such keys are one-use reconstruction correspondence, never new durable identity.
No matching by labels, XML positions, coordinate similarity or Java references
as durable identities. Snapshot capture must not assign persistent IDs or alter
the original registry. An inactive/foreign/replayed private key must fail closed.
Prefer existing serialization/load-purpose seams over a general new framework.

Install/consume restored native input state in dependency order through the
normal loading/update lifecycle, then verify typed restoration and durable
bindings. Restore failure remains explicit catastrophic failure with the
original mutation error retained. Do not remove admission guards until their
positive replacement and exact rollback regressions pass. Unsupported states
retain a typed reason identifying the actual missing restorer, not a blanket
ordinary-path or unrelated-document prohibition.

A shared typed NativePathState2D value captures defining geometry, source
context and domain: line coefficients AND origin; ray/segment endpoints;
conic matrix/frame; arc start/end/extent/orientation. It is freshness evidence,
not an identity, and also serves F5. File fidelity and transactional support
remain separately observable and tested.

## F2 — Transversal continuation using existing certified models

Retain the structural affine-circle and existing C1/R6/Spline permissions.
Adapt ConstructionBoxModel2D's existing v3 evaluators, jets, predicates,
selectors and certified components. Do not introduce an example-specific
LINE_CIRCLE evaluator or substitute a render polyline. Capture only faithful
reconstructible programs and uniformly decided structural selection.

Separate prior address, admitted chart, candidate discovery, local proof,
normal forward evaluation, and final freshness/publication. A chart is bound
to source/definition/revision, provider, branch, component, lift and selection.
The prior address is a constraint, not permission. Global UNRESOLVED results
retain their meaning; no global nearest/minimum/uniqueness claim is added.

An optional local projection provider may use

    g(u,q) = (F(u)-q) dot F'(u)
    g_u = ||F'(u)||^2 + (F(u)-q) dot F''(u).

On one lifted interval J and the whole segment between accepted and requested
targets, prove valid predicates/selection, a positive speed lower bound and
g_u >= mu > 0. Strict opposite endpoint signs establish one interior root for
every target on that segment. The selected root therefore continues locally;
its parameter variation is bounded by sup||F'||/mu times target displacement.
Use outward enclosures, budgeted isolation and declared parameter error.
Small residual alone is not a parameter-error certificate.

Initial correspondence must anchor to the old exact semantic argument and its
forward image, accounting for numerical forward enclosures rather than assuming
rounded coordinates are an exact real image. Subsequently retain the actual
accepted target and certified root enclosure, not just its floating representative.
A replacement chart must contain the prior root enclosure and preserve equation,
component and selector. The numerical representative is evaluated through the
normal forward binder; it is not claimed to be an exact orthogonal projection.
Repeated identical requests must retain the accepted representative exactly.

This use of second-order jets is an explicit additional consumer relative to
certified-construction-model section 10.7, not a silent reinterpretation of R6/H1.
C2 is sufficient only for this optional provider. C1 charts and structural proofs
remain independent; no universal C2 requirement or gesture-local silent switch
between unrelated selection equations is introduced.

At an included genuine DOMAIN_END, constrained-root/KKT endpoint conditions
may establish unilateral continuation and return into the domain. Never clamp
to an internal chart edge, unresolved band, certified transition or structural
event merely because a binary-safe endpoint is included. Periodic continuation
requires existing certified component/selection correspondence, lifted domain
coordinates, periodic model enclosures and outward seam/canonical-rounding error.
No seam correspondence is inferred from coincident endpoint coordinates.

Required transverse families: circular affine compositions; v3 segments/arcs;
regular LINE_CIRCLE; direct admitted interval sources; SplineV2; additional v3
operations with sufficient uniform predicates and jets. Tangency, gaps,
zero speed, undecided selectors, unproved curvature bounds or exhausted budget
retain explicit barriers and last valid state. A missing provider is recorded
as a missing capability, not as geometric impossibility.
