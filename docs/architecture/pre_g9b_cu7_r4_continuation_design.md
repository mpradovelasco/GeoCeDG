# CU7 R4 — Adaptive continuation and captured similarities

2026-11-04. Candidate design recorded before its Java changes. Implementation,
shared kernel layer. Authority: the author R4 task, live R3 contracts and the
immutable `cu7-r3-independent-audit` probes/receipts. R3, R6/H1, D1 and F8 remain

author approval.

## Demonstrated changes

The independent MEET unit-circle probe supplies a straight request segment from
the accepted target at parameter .11 to the target at 1.91, radius .5. One R3
chart refuses it while 24 portions of the same request segment establish local
continuation. The composition probes create points on a certified parabola's
translation, rotation, negative dilation and nested image, but continuation is
misdispatched to a polynomial interface whose effective capability is absent.

## One event, several charts, one publication

Keep the R3 equation `g=(F-q).F'`, positive speed, strict `g_u>=mu>0`, whole-chart
predicate/selector proof, genuine DOMAIN_END KKT policy and certified circle-seam
correspondence. Attempt a chart for the requested target interval. If sufficient
evidence is absent, bisect the request-path parameter, prove the first part, then
the second from its retained root witness. This is adaptive depth-first proof,
not a fixed list of geometric samples or a larger single-chart budget.

Internal targets enclose the exact affine interpolation of the original request
endpoints. Initially the first endpoint encloses exact `F(a0)`; later it is the
actual previously accepted floating target. Outward interpolation avoids treating
rounded midpoints as exact points on the request segment. Root enclosures for
these intermediate target enclosures are transported unchanged to the next chart.
Each new chart contains the entire previous root enclosure and proves the same
equation, captured raw selector, component, provider orientation and transform
lineage. Only the final target is the exact supplied binary64 coordinate pair.

Internal representatives/lifts are proof coordinates. They never edit P, invoke
the forward binder, propagate the DAG, create a snapshot or store Undo. On success
the existing service binds only the final address and the existing host publishes
it once atomically. Any last-chart, budget, source/revision, authority or forward
failure discards the whole transient chain; the gesture witness advances only
after successful publication.

Per-chart represented-parameter change bounds include both root/representative
errors and period alignment. Sum them with outward rounding for the event bound.
The final parameter-error bound is the final root-enclosure bound, not a claim
that floating representatives solve g exactly. Intermediate root uncertainty is
retained, rather than replaced by its midpoint. The world-radius check remains the
existing declared floating-point final forward proximity check, not a certified
geometric distance or global minimum.

Before expensive whole-chart subdivision, evaluate g_u on the prior root and
candidate-target enclosure, and test candidate chart endpoint signs. A definite
nonpositive g_u there disproves that particular strict chart and triggers request
subdivision. It does not prove geometric impossibility. All interval runs,
correspondence checks, failed attempts and adaptive subdivisions share the one
event work ceiling. Existing refinement limits plus a versioned finite chain-depth
ceiling stop grid stagnation and pathological attempts. No budget resets between
subrequests or fresh semantic sessions. Exhaustion remains BUDGET_EXHAUSTED.

## Similarity model transport and effective dispatch

Add a focal immutable continuation-model adapter. Walk captured
`LocusSimilarityEvaluator2D` snapshots to a faithful reconstructible v3 root,
bounded by the existing composition policy. Require noncollapsed finite maps,
shared provider/domain/orientation and copied branch/component lineage at every
link. The normal similarity algorithm already transports that structure; the
adapter verifies it rather than matching coordinates. A signature records each
source identity/revision, captured transform signature and ordered chain.

Replay the root ConstructionBoxModel once for F/F'/F'' and all predicates. Apply
captured transforms innermost first: values receive A and b; both derivative
orders receive only A. Root validity predicates and raw selectors remain attached
to that same run. Outward operations retain transformation coefficient/function
uncertainty, without flattened rounded coefficients or inverse mouse mapping.

The admitted transformation kinds are the existing constructive similarities:
translation, rotation, point/line reflection and finite nonzero dilation. Their
geometric maps have `A^T A=s^2 I`, s>0, by the captured kind's contract. In
particular, rounded normalized reflection coefficients are not asserted to have
exact unit norm: retain the normalization enclosure already documented by
LocusSimilarityTransform2D, and enclose its corresponding exact geometric map.
Enclose trigonometric coefficients with the existing certified trig machinery.
Also require the outward determinant to exclude zero; overflow, indeterminate
normalization, zero dilation, missing jets or unproved correspondence refuse.
Negative scale/reflection changes image orientation but never reverses the
declared source parameter or fabricates a new component/lift.

### Focal-run transport correction, recorded before its implementation

The first R4 shared run accepts all seven local wrapper families and the direct
single-event chord, but the three-wrapper seam chain exhausts the unchanged 512
proof-work ceiling. Each root jet currently repeats all three immutable maps.
Compose their coefficient **intervals**, once per event, in captured order:
`A=A_outer A_inner`, `b=A_outer b_inner+b_outer`, with every operation outward.
Retain the individual maps/signatures and typed similarity checks. This is not
flattening to rounded binary64 coefficients, fitting a transform or increasing a
budget. Evaluate the root jet once and transport its three orders by the resulting
outward affine enclosure once. The `similarityApplications` counter then counts
actual composite-jet transports; correspondence checks still count all captured
links. Reject a composite determinant enclosure containing zero. Keep the failed
receipt and unchanged extreme regression; root measures the successor cohort.

The first implementation's additional bounds are 24 request-bisection levels,
12 radius trials per chart attempt and 6 parameter-box proof levels. The one
policy subdivisions ceiling (initially 512) remains the total charged-work bound,
including failed attempts, request subdivisions and interval/transformation work;
none of the individual ceilings resets or multiplies that allowance.

Historical continuation is selected only when supportsPiecewisePolynomial or
supportsCertifiedAffine is actually true. Interface presence alone is insufficient.
Direct R3 affine-circle priority and the independent C1 fallback remain; the
optional projection provider's C2 requirement does not become universal.

retains the prior exact address and creates no snapshot. Timing is observational,
not an SLA or pure GUI latency, and no stage medians are treated as additive.
