## Exact creation clause

Add `INDIVIDUAL_FORWARD_ADDRESS_CREATION`, exclusively for publication of a new point.
Its permission and evidence are independent of R1/R6 and R2/H1; their results, guarantees,
and rejection rules remain unchanged. An inverse result does not itself authorize this
operation. Discovery may reuse its semantic candidates only under its safety/budget barriers.

An offer requires one coherent current durable source, valid definition/provider/revision,
faithful reconstructible class-v3 construction program and coherent documentary authority;
COMPLETE existence inventory; a positive-dimensional certified continuous component;
structurally resolved selector containing the argument; a complete canonical address; and
normal forward binding of that same address with finite evaluation. An active constructive
authority without an approved capture transfer is rejected. No C1, nonzero speed, minimum,
inverse completeness, or local/global injectivity is universally required for creation.

The finite world request and positive radius filter the computed forward residual. The
initial implementation declares `FLOATING_POINT_UNCERTIFIED` proximity only: this is a
discovery threshold, not a certified bound on ideal geometry, STRICT, minimum or uniqueness.
Every offer requires explicit selection, including a single offer. Handles are private,
single-use, synchronous-thread owned and revalidated before publication. Discovery,
forward validation, confirmation and publication share a cumulative bounded evaluation
session; cache clearing never resets charged work. Exhaustion, nonfinite values, collapsed
images, unsafe discovery, stale source/Q, ambiguous selectors or correspondence failures
reject without publication. No fallback follows a publication failure.

Only the existing forward address and legitimate DAG parents persist. Click/Q, residual,
search evidence and selection handles are transient. Q is not added as a parent. Distinct
preimages remain distinct. Only provider-proved periodic equivalences canonicalize seams.
PARTIAL inventories, arbitrary evaluators, point/collapsed components and unsupported
captures remain outside this first table. No new existence or reconstruction system is added.

## Continuation and user interaction

The separate continuation candidate defines its sufficient local chart evidence before
implementation. Old address is a constraint, not a permission; certified existence of a
domain path does not imply unique geometric inverse selection. Rejection retains the last
valid state. Edits preserve point ID and dedicated semantic state, propagate through the
normal DAG and use one Undo per gesture. No new point or generic Path is introduced for L.

Desktop captures world request and world discovery radius before any modal source selector.
Its screen hit only chooses the source. A view change cannot reinterpret the captured click.
`Allow dragging` defaults true; false uses the native fixed flag, preserving dependence on L.
The same native lock can be offered for ordinary 2D lines, segments, rays and conics. Their
reference-Q creation uses the existing native point-on-path constructor, with Q transient;
it retains native snapping guarantees and makes no new uniqueness/certification claim.
