# GeoCeDG Construction quick guide — SUPERSEDED / LEGACY

**Status: SUPERSEDED.** This document is retained only so that existing links
and historical references keep resolving. It is no longer maintained, it is no
longer the source of **Help → GeoCeDG user guide**, and it must not be treated
as a description of current product behaviour.

Its practical workflows, menu routes and worked examples were audited against
the current product, corrected where they had become stale, and carried into the
two official user guides:

| Edition | File |
|---|---|
| English | [GeoCeDG user guide](geocedg_user_guide_en.md) |
| Español | [Guía de usuario de GeoCeDG](geocedg_user_guide_es.md) |

Known reasons why the previous content of this path was stale:

- it framed the application as a candidate under review rather than as
  GeoCeDG 1.0.0;
- it instructed the reader to launch with an argument to enable semantic-curve
  creation, which has been normal default behaviour since `PRE-G9B-P1`;
- it referenced author-side diagnostic fixtures and a re-smoke checklist that
  are session evidence, not user instructions.

The historical execution evidence that cited this guide is preserved unchanged
under `docs/validation/` and `geocedg/validation/`; this supersession does not
rewrite it.
