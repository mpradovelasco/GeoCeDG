# Legacy intake area

`docs/legacy/` was the provisional author-supplied intake area used at the
start of G3. The original files were inspected before classification.

- Scientific and technical PDFs now live under `docs/references/cedg/` and
  are registered in `docs/references/cedg/catalog.yml`.
- `Templatev7.ggb` is preserved byte-for-byte under
  `models/legacy/template-v7/original/` and registered by its model manifest.

New material may be staged here only long enough to establish provenance,
rights status, hashes, and its durable repository location. This directory is
not a model catalog or an executable-resource store.
